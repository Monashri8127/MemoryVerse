# 🧠 MemoryVerse: AI-Powered Digital Identity System

MemoryVerse is an intelligent, graph-driven personal portfolio manager and digital memory system. It ingests career milestones, technical skills, certifications, and academic accomplishments, auto-categorizes them using LLMs, and maps them into an interactive relationship graph and chronological timeline.

---

## ✨ Features

- **Document Ingestion & AI Parsing**: Upload or input professional milestones with automated category and skill tagging powered by Google Gemini API.
- **Relationship Graph**: Interactive node-edge network graph built using NetworkX and PyVis to visualize connections between skills, projects, and experiences.
- **Interactive Timeline**: Chronological view tracking skill progression and career milestones over time.
- **Semantic & Smart Search**: Instant querying across all persistent memory records.
- **Data Persistence**: Local and cloud JSON persistence ensuring data continuity across user sessions.

---

## 🛠️ Tech Stack

- **Frontend & UI**: [Streamlit](https://streamlit.io/)
- **Graph Visualization**: NetworkX, PyVis
- **AI / LLM Integration**: Google Gemini API (`google-generativeai`)
- **Language**: Python 3.10+
- **Deployment**: Streamlit Community Cloud
